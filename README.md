# R# 📸 Responsive Image Gallery Website

A modern and responsive Pinterest-style image gallery website built using **HTML5 and CSS3**. This project features a masonry-style image layout, responsive navigation sidebar, search bar, and horizontally scrollable categories.

## 🚀 Features

- 📱 Fully Responsive Design
- 🖼️ Pinterest-Style Masonry Image Gallery
- 🔍 Search Bar UI
- 🎨 Attractive Category Buttons
- 📌 Responsive Sidebar Navigation
- 📲 Bottom Navigation for Mobile Devices
- ✨ Smooth Image Hover Effects
- 💻 Desktop, Tablet & Mobile Support

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Media Queries
- CSS Columns
- Remix Icons

## ⚙️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Make sure all images are in the correct folder.
4. Open `index.html` in your browser.

## 🎯 Project Purpose

The main purpose of this project is to practice HTML and CSS skills, understand responsive web design, and learn how to create a Pinterest-inspired masonry image gallery.
